# Safer by the Thread

Reading the fine print on babies' and kids' things so you don't have to.

A static guide to toys, beds and bedding, ice trays and footwear for toddlers. Each entry lists what its maker says it is made of, what it says is absent, and what no page states. Visitors filter the list with switches whose defaults are one family's preferences. The site reports what makers and stores say; it does not rate safety or risk.

## Files

- `data.json`: every entry (schema 3), the filter criteria and the "questions makers can answer" list.
- `glossary.json` / `glossary.md`: the materials glossary, generated by `glossary_build.py`.
- `img/`: one product photo per entry, `img/<key>.jpg`.
- `template.html` + `build.py`: render the single-page site.
- `research/photo-urls.tsv`: photo source URLs from the original toy research.

## Build

Needs Python 3 and Pillow (`pip install pillow`).

```sh
python3 -I build.py site      # writes site/index.html, site/img/ and site/files.json
python3 -I glossary_build.py . # only after editing the glossary source
```

Open `site/index.html` in a browser to check it.
